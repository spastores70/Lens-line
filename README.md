# Lens & Line

An affiliate-ready, SEO-optimized eyewear guide built around FYTOO. The site includes a five-slide hero carousel, curated product-style cards, a frame finder, a practical buying guide, responsive layouts, affiliate disclosures, and social-sharing metadata.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Replace the centralized `SHOP_URL` value in `app/page.tsx` with the approved FYTOO affiliate tracking URL before promoting campaigns.
